# Repository conventions

Use compact, precise mathematical prose. Explain hypotheses and physical meaning.
No unfinished proofs, added axioms, unsafe declarations, or native_decide.
Do not assume negative current or the probability increase in an existence theorem.
Distinguish conditional analytic lemmas from an instantiated free-particle result.
Verify compilation and all transitive declaration axioms. Preserve attribution.
Use main for checked work. Leave publication to the owner in GitHub Desktop.
